# Portrait asset

Drop the official photograph of Anjan Prasad here as:

    public/images/anjan-prasad.jpg

It is consumed by `src/components/brand/Portrait.tsx` and appears
automatically in the homepage hero and the About page. Until the file
exists, both locations render a branded placeholder — no code change is
needed once you add the image.

Recommended: a high-resolution JPG/WebP, portrait or square crop, subject
roughly centred (the hero frame is ~3:4, the About frame is 4:5).
